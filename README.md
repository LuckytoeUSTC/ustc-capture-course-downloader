# 录课目录助手

本人曾使用 [capture-courses](https://github.com/TMYTiMidlY/capture-courses) 辅助学习，但网站更新后，该工具无法继续使用，于是尝试开发了这个录课下载工具。开发过程中参考了该项目开发者对在线视频平台的分析与技术讨论。

目前，本工具只能获取当前账号已开放课程的录课目录，提供视频预览和本地下载任务管理，支持暂停、取消、拖动排序、断点续传及同时下载两路视频。可通过课程网址或网页数字编号（如 `18370`）查询目录。

**尚未实现全站课程访问、未开放课程的观看、全站搜索，也未实现教学课程号（如 `BIO4502e.01`）到网页编号的转换。请勿将本工具与 capture-courses 的功能混淆。**

技术困难主要有两部分：

- **课程访问**：capture-courses 开发者在 [Issue #15](https://github.com/TMYTiMidlY/capture-courses/issues/15#issuecomment-2607170193) 中指出，平台更新后 API 开始针对登录账号鉴权。当前工具使用 `/api/frontend/study-capture-courses/{网页编号}/…` 获取目录和录课详情，尚未找到能够访问未开放课程的方式。**推测**服务器会结合账号与课程授权关系判断访问权限；具体检查发生在哪个接口、采用哪些规则，尚未验证。知道课程编号或修改前端不能据此保证获得访问权限。
- **视频地址**：已观察到原网页的 `play_url` 请求返回 `302`，跳转到带 `ts` 和 `token` 参数的视频地址，而同一播放入口在新标签页直接打开返回 `403`。**推测**请求上下文或凭据参与了校验，但尚不能确定是否检查 Cookie、Referer，或 token 的有效期与绑定关系。详情接口返回 `200`、包含视频地址，也不能证明该地址在任意请求方式下都可使用。

目前的开发重点是已有访问权限课程的目录与下载管理。接口返回视频地址也不等于获得下载授权。
## 安装

1. 安装 **Node.js 22 或更新版本**，下载并解压本项目。
2. 浏览器安装 **Tampermonkey（油猴）**。
3. 在油猴中新建脚本，将 `recording-helper.user.js` 全部复制进去，保存。

## 使用

1. 双击 `启动下载服务.cmd`，保持窗口打开。
2. 登录 [中科大在线视频平台](https://v.ustc.edu.cn/)，进入“我的课程”中的一门课。
3. 点击右下角的下载图标，再点 **当前课程**。也可以输入课程网址或网页数字编号（如 `18370`），按回车查询。
4. 勾选录课，点击 **下载**。显示“任务已接收”后即可关闭网页。

视频保存在 `C:\Users\用户名\Downloads`。教师画面和电脑录屏分别保存，文件名包含周数、星期、日期、课程名和视频类型。重名文件直接跳过，不加后缀。

## 管理下载

- **网页**：任务右侧可暂停、继续或取消；拖动左侧三横线调整顺序。最前面的两项可运行任务同时下载，其余排队。
- **命令行**：按 `1`～`9` 取消对应序号的任务，按 `0` 取消全部；`Ctrl+C` 退出服务。
- **暂停**保留进度；**取消**删除任务和未完成文件，已完成的视频保留。
- 重启服务会继续排队中的任务，暂停任务需手动开始。已完成记录会清除。

## 更新与常见问题

- 更新时替换项目文件和油猴脚本，重启服务并刷新网页；同名油猴脚本只启用一份。
- 油猴提示连接 `127.0.0.1` 时，选择允许。
- 下载失败时，回到课程页面重新提交，刷新视频地址。

`下载录课.cmd` 是保留的旧 HTML 拖入入口，日常使用上述流程即可。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `recording-helper.user.js` | 油猴界面。 |
| `download-server.mjs` | 本地服务和任务队列。 |
| `video-downloader.mjs` | 视频下载和断点续传。 |
| `terminal-dashboard.mjs` | 命令行任务表和进度显示。 |

`download-course.mjs` 仅保留为旧 `下载录课.cmd` 的兼容入口。

## 特别声明

本工具仅供校内学生个人学习使用。**请勿将课程视频、音频、转写文本或其他课程内容私自上传至互联网或公共平台，也不得将课程内容用于商业用途。** 请尊重任课教师和其他出镜人员的权益，遵守学校及平台的使用规定，仅访问和下载已获授权的内容。

需要录课时，优先向任课教师或管理员申请开放权限。平台更新可能导致工具失效，请勿完全依赖本工具。
