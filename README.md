# 录课目录助手

在中科大录课网站选择课程视频，通过本地程序下载。支持预览、暂停、取消和拖动排序，同时下载两路视频。

## 安装

1. 安装 **Node.js 22 或更新版本**，下载并解压本项目。
2. 浏览器安装 **Tampermonkey（油猴）**。
3. 在油猴中新建脚本，将 `recording-helper.user.js` 全部复制进去，保存。

## 使用

1. 双击 `启动下载服务.cmd`，保持窗口打开。
2. 登录 [中科大录课网站](https://v.ustc.edu.cn/)，进入“我的课程”中的一门课。
3. 点击右下角的下载图标，再点 **当前课程**。也可以输入课程网址或编号，按回车查询。
4. 勾选录课，点击 **下载**。显示“任务已接收”后即可关闭网页。

视频保存在 `C:\Users\用户名\Downloads`。教师画面和电脑录屏分别保存，文件名包含周数、星期、日期、课程名和视频类型。重名文件直接跳过，不加后缀。

## 管理下载

- **网页**：任务右侧可暂停、继续或取消；拖动左侧三横线调整顺序。最前面的两项可运行任务同时下载，其余排队。
- **命令行**：按 `1`～`9` 取消对应序号的任务，按 `0` 取消全部；`Ctrl+C` 退出服务。
- **暂停**保留进度；**取消**删除任务和未完成文件，已完成的视频保留。
- 重启服务会继续排队中的任务，暂停任务需手动开始。已完成记录会清除。

## 更新与常见问题

- 更新时替换项目文件和油猴脚本，重启服务并刷新网页；同名油猴脚本只启用一份。
- 油猴提示连接 `127.0.0.1` 时，选择允许。
- 下载失败时，回到课程页面重新提交，刷新视频地址。

`下载录课.cmd` 是保留的旧 HTML 拖入入口，日常使用上述流程即可。

## 项目文件

| 文件 | 用途 |
| --- | --- |
| `recording-helper.user.js` | 油猴界面。 |
| `download-server.mjs` | 本地服务和任务队列。 |
| `video-downloader.mjs` | 视频下载和断点续传。 |
| `terminal-dashboard.mjs` | 命令行任务表和进度显示。 |

`download-course.mjs` 仅保留为旧 `下载录课.cmd` 的兼容入口。
